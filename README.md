# CIMALTEA 2026 — Gestão

Ferramenta de gestão de músicos e quartos para a participação da Banda Musical de Monção no 51.º Certamen Internacional de Música "Vila d'Altea".

## Desenvolvimento local

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run build
```

A pasta `dist/` contém o site estático pronto a publicar.

Your site is live at https://andre-pereira01.github.io/gestao-cimaltea/
